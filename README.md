# Expense Tracker

## Overview
Expense Tracker is a web-based personal finance management application that helps users track their income and expenses.

## Features
- User Authentication
- Transaction Logging
- Monthly Financial Summaries
- Expense Categorization
- Graphical Expense Breakdown
- CSV Report Generation

## Prerequisites
- XAMPP (PHP, MySQL)
- Web Browser

## Setup Instructions
1. Clone the repository to `htdocs` directory
2. Open MySQL Admin (phpMyAdmin)
3. Create database and run `config/setup.sql`
4. Configure `config/database.php` if needed
5. Access via `localhost/expenseTracker`

## Technologies
- PHP
- MySQL
- HTML5
- CSS3
- Chart.js

## Security
- Passwords hashed with bcrypt
- Session-based authentication
- Prepared SQL statements
